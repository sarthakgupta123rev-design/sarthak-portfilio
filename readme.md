# Sarthak Gupta — Developer Portfolio

A responsive editorial-style developer portfolio inspired by project-index layouts: large typography, ruled project rows, a hover-reactive preview panel, project descriptions, coding statistics, education, skills, recognitions, and contact.

## Run locally
Open `index.html` in a browser. For best results, use a local server such as VS Code Live Server.

## Deploy for free
1. Extract the folder.
2. Upload the folder contents to Netlify Drop, or push the folder to GitHub and import the repository into Netlify.
3. Keep `index.html`, `styles.css`, and `script.js` together.

## Before publishing
- Add your actual GitHub and LinkedIn profile URLs.
- Confirm the LeetCode profile URL and update stats as they change.
- Add public repository/demo links for projects when ready.
- Coding statistics are snapshots based on supplied screenshots.
- No unverified repository links or fabricated awards are included.
